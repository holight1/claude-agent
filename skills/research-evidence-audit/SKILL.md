# 研究证据审计

**状态**：enabled
**消费者**：共享
**投影**：DS-common.md
**来源**：本框架抽取记录被 Codex review 阻断的 7 处 + 三起同形状的计数事故
**核心判断**：这条引文，原文里真的连着这么一句吗？这个数字，是哪条命令产生的？

**本 skill 是判据，不是完整清单。** 判据的由来与实测事故在下方「判据来源」的记录与 `evals/EVALS.md` 里，正文只留可执行的检查。

## 跨角色必读

### 引文

- 引文必须是原文**连续**的一段。非连续原文**不得缝成一条**
- 转述时原样保留：**行为者、条件、时序、情态（may / 建议 / 预计）、否定保证、例外**
- 注意这句话在原文里是**论据、反例、还是被否的提案**——身份搞反比引错字更难发现
- 拿不准就**给原文，不只给转述**

### 数字

- 每个数字**附产生它的命令**。预期值、文档记载值、口述值都不是实测值
- 写下之前问：这个数统计的**单元**是什么？有没有把译文、别名、重复项算进去？
- 「我用脚本核过了」不等于「脚本核的是这个对象」——先看它处理了几个单元

### 报告

分开写，不许混：**我核对到不对**（有出处与原文）／**我认为不合适**（判断，无实据）／**我无法核对**（必填：哪些材料不在手里、哪些结论只能存疑）。

「无法核对」空着，会让「通过」被读成全面核对过。

## 何时用

**触发**：调研 / 源码解读 / 知识抽取 / 事实报告返回；准备把一条带出处的结论写进持久文档；引用他方文档或外部页面。

**不触发**：本轮自己刚跑的命令输出（那属于 `task-acceptance-replay`）。

## 要防的诱人错误

每一条都实际发生过，且当时都有正当的推理路径。

| 诱人错误 | 失效形态 |
|---|---|
| **情态被加强** | 源文的 "**may**"（可能）在转述里变成「**会**」，同时丢了主语，还把一个**正面论据**倒过来当反例 |
| 设计意图写成既成行为 | 「文档规定 X」→「系统会 X」 |
| 他方限定被丢掉 | 区间估算 / 非实测 / 产品目标，转述时都变成了断言 |
| **引文缝合** | 把一节的主语和另一节的谓语拼成一句连续引文。审查者能看出不是原句，但**未必能看出哪半是真的** |
| **计数口径** | 把一个目录下的文件总数当成某一语言的篇数，而另一半是译文。错误会顺着传播进多个下游节点 |
| **口述数字当事实** | 把「几个人开发了几个月」当事实，实测贡献者数量差一个量级；在它之上还叠了两层推论 |
| **校验作用于错误的对象** | 提取器的格式假设与被校验文件的实际格式不符 → 实际提取 **0 条**，却报告满分命中。事后真核发现相当比例的引文原文不存在 |
| 设计 = 效果 | 「某个成熟项目经历过血泪所以这套有效」——没有反事实，效果未被验证。可背书的只有建设顺序和单条机制的内在逻辑 |

后三条同一个形状：**一个不是我算出来的、或没有产生它的命令的数字，进了持久产物。**

## 判断程序

### 1. 先问校验工具处理了几个单元

在相信任何自动核对之前：**让它打印处理了多少单元**。0 个，或数量与预期不符 → 该次校验**无效**，不是通过。

「我用脚本核过了」不等于「脚本核的是这个文件」。

### 2. 逐条核对，不抽查

- **路径存在性**：每个引用的文件 / 章节 / URL 是否真的存在
- **逐字命中**：引文必须是原文**连续**的一段。非连续原文不得缝成一条
- **上下文**：这句话在原文里是**论据、反例、还是被否的提案**？已发生的形态：把一条「被否方案对现行设计的批评」写成了现行规范
- 名称一致：类型名、接口名、字段名、参数值

### 3. 情态与限定的保留清单

转述时必须原样保留：**行为者、条件、时序、情态（may / 建议 / 预计）、否定保证、例外**。

拿不准就**给原文，不只给转述**。

### 4. 数字的口径

每个数字附**产生它的命令**。写进持久产物前问三句：

1. 这个数是我算的，还是别人说的？
2. 它统计的单元是什么——有没有把译文、别名、重复项算进去？
3. 换一条独立命令算，能不能得到同一个数？

### 5. 区分三种断言

报告里分开写，不许混：

- **我核对到不对**（有出处与原文）
- **我认为不合适**（判断，无实据）
- **我无法核对**（必填：哪些材料不在手里、哪些页面取不到、哪些结论只能存疑）

「无法核对」空着，会让「通过」被读成全面核对过。

### 6. 制度设计 ≠ 制度效果

一个项目**如此设计**，只能证明它如此设计。宣称有效需要反事实或运行证据。没有时，最多说「其建设顺序与单条机制的内在逻辑可借鉴」。

## 停止条件

- 校验工具处理单元数为 0 → 停，重做校验，不要报结论
- 引文找不到连续原文 → 该条作废，不要改写引文去迁就结论
- 原始材料不在手里 → 写进「无法核对」，不要凭印象补

## 报告格式

| 结论 | 出处（路径 + 章节） | 原文 | 核对结果 |
|---|---|---|---|

加上必填的「无法核对的范围」。
