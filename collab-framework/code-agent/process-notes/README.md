# process-notes/ — 流程缺口记录

**用途**：任务暴露出的**流程本身**的缺陷落在这里，作为 `~/claude-agent` 的改进建议来源。任务终审区写「这次的判决」，本目录写「下次怎么不再发生」。

**制度**：见 skill `process-gap-capture`。

## 规矩

- 命名 `NNNN-<短横线短语>.md`，**只追加，不改写既有记录**
- **一条记录一个缺口**
- 🔴 **不直接改 `~/claude-agent`**——那是上游框架，改动权在用户。本目录只产出可采纳的建议
- 本项目的 `REVIEWER.md` / `CLAUDE.md` / `DS.md` 可先改以止血，但记录里必须写明「本仓已临时落地，框架未同步」
