# 知识库索引

本目录按主题分文件存储项目知识。DeepSeek 按任务相关性读取，避免全量加载。

## 主题文件列表

| 文件 | 内容 |
|------|------|
| 01-project-structure.md | 项目结构、模块划分、文件布局 |
| 10-changelog.md | 知识库变更日志 |

## 使用规则

- 按任务需要读取相关主题文件，**不要一次性读取所有文件**
- 新增知识时更新对应主题文件，并在 `10-changelog.md` 添加一行记录
- 如现有主题文件不够用，按 `02-`、`03-` 编号新建主题文件，并在此 README 中登记
